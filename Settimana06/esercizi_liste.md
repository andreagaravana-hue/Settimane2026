# Esercizi sulle liste


## Negativi?

Data una lista di numeri interi, dire se tale lista contiene anche dei numeri negativi. 

**Addendum** Se sì, dire quanti

## Doppie?

Data una lista di stringhe, dire se tale lista contiene almeno una stringa con delle lettere "do**pp**ie". 

## Crescente?

Data una lista di numeri reali, dire se i numeri in essa contenuti formano una sequenza (strettamente) crescente.

## Ricerca duplicati

Data una lista di numeri reali, determinare se contiene dei valori duplicati (anche non consecutivi).
